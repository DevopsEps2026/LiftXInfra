Crane IoT Monitoring Services

14Crane IoT Integration Engineer / Field Technician

Role: Support OEM-approved telemetry integration for ACE Hydra, Escorts Kubota / Farana and TIL / Manitowoc cranes, from field installation to fleet dashboards.

Service focus: Passive CAN/J1939 data acquisition, sensor installation and calibration, industrial LTE/GNSS gateways, engine and hydraulic monitoring, load and fuel telemetry, fleet dashboards, alerts and gateway diagnostics. Signal availability must be verified for each crane.

Requirements and skills: Electronics, instrumentation, automotive engineering or relevant field experience; CAN/J1939 diagnostics, electrical schematics, MQTT/TLS, gateway commissioning and safe on-site troubleshooting. State whether you are applying for integration engineering or field installation.

Safety and data integrity: Use isolated, OEM-approved read-only connections; never bypass crane safety systems or write control commands to the CAN bus. Keep simulated, unavailable and verified live readings clearly separated.

Current platform: Our 12-crane dashboard is a browser simulation only. No real gateway telemetry is connected; live integration is planned work, not an existing deployment.
