# LiftX Infra website template

A responsive, ready-to-run static website made with HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `about.html` — dedicated About Us page
- `services.html`, `projects.html`, `technology.html`, `contact.html` and `careers.html` — dedicated pages linked from the navigation
- `style.css` — layout, colors and responsive design
- `technology-menu.css` — responsive Technology mega-menu
- `script.js` — mobile navigation, client carousel and enquiry form behaviour
- `assets/` — place your logo and local images here if you want to use them
- `Clients/` — client cards displayed in the automatic carousel

## Run on your computer
1. Extract the ZIP file.
2. Open the `LiftXInfra_Website` folder.
3. Double-click `index.html` to preview the home page and its automatic client carousel, then use the navigation to open the other pages, including Careers.
4. For editing, open the folder in Visual Studio Code.

No build tools are required. The preview uses online Unsplash images and Google Fonts, so those assets need an internet connection.

## Before publishing
1. Confirm the contact email, phone number and website in `index.html` are correct before publishing.
2. The enquiry form uses a `mailto:` draft addressed to `liftxinfra@gmail.com`; it does not securely submit enquiries to a server. For a production form, connect a trusted form service or backend.
3. Replace the sample project cards and imagery with real project photos and approved descriptions.
4. Add your actual company logo, legal business details, privacy policy and any required terms.
5. Verify that you have permission to use all photos and content before launch.

## Put it online
You have purchased the domain but have not configured hosting yet. You will need a hosting provider or static hosting platform, then:
1. Upload the website files (the contents of this folder) to the hosting provider.
2. Follow the host's instructions to connect `liftxinfra.com` using DNS records.
3. Configure both `liftxinfra.com` and `www.liftxinfra.com`, and choose one as the canonical address with a redirect.
4. Enable HTTPS/SSL in your hosting settings.
5. Test the site on mobile and desktop after DNS changes propagate.

Do not change DNS records until you know which hosting provider you are connecting to. Keep a copy of the current DNS records first.
